# seyo_landing

seyo.. 랜딩 페이지(`index.html`)와 포트폴리오 페이지(`works.html`). 빌드 없는 정적 HTML/CSS/JS.

## 로컬 실행

```bash
python serve.py   # http://127.0.0.1:8080 (캐시 비활성화)
```

## 구조

- `assets/css/style.css` — 디자인 토큰(#1D1D1F, #F5F5F7, 베이비핑크/블루), 타이포, 반응형
- `assets/js/main.js` — 사진 캘린더·태스크 보드 렌더링, 목업 스케일링, 스크롤 등장
- `assets/fonts/PretendardVariable.woff2` — Pretendard Variable (OFL)
- `assets/img/` — seyo.. 워드마크, 파비콘, 이모지 스티커
